# ¡Ah Carbón! Hamburguesas · Menú de pedidos

Menú web que arma el pedido y lo envía por WhatsApp.

- `public/index.html`: la página. El menú, precios y número de WhatsApp se editan en el bloque `CONFIGURACIÓN`.
- `public/img/`: fotos del menú.
- `wrangler.jsonc`: configuración de Cloudflare (el nombre debe coincidir con el Worker `ah-carbon`).

Panel del negocio: agregar `#negocio` al final del link.
